## Sange-native verbs (no direct git equivalent)

These commands are documented inline above (Power tier). They have no underlying `git` command — Sange invents them on top of the VCS surface.

- `sange undo` — Safe reversal of the last destructive operation using reflog + audit chain.
- `sange review` — Local PR-style review of staged changes.
- `sange recover` — Restore from a crash mid-publish or mid-purge.
- `sange variant` — Multi-dimensional variant matrix manager (ADR-032).
- `sange scaffold` — Premade Operations Kit materialization (§6.12, §7.11).
- `sange doctor` — Health probe — local + container + variant + audit.


## How to update this appendix

- Add a new Sange wrapper for a Git command → append a row to the `ENRICHMENT` dict in `tools/generators/git_catalog.py`.
- Reclassify a tier → edit the row's `tier` field there.
- Upgrade Git → the next run picks up new commands automatically; review the diff and enrich the newly-appearing rows.
- Verify integrity → `python tools/generators/verify_generated.py`.
- Regenerate → `python tools/generators/all.py --only T-G-001 --write`.

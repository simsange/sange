## Plugin extensions

Per ADR-020, third-party plugins may ship additional kit fragments. Each plugin manifest declares its files separately and is signed independently. The Sange runtime kit-loader treats first-party and plugin fragments as distinct trust roots — a compromised plugin cannot forge entries in the canonical `templates/MANIFEST.toml`.

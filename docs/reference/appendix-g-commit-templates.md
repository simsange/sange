## Programmatic access

The library at `templates/commit-templates/default.toml` is consumed by the §6.8 commit-message subsystem at run-time. Users extend it via `~/.sange/commit-templates/user.toml` and `${repo}/.sange/commit-templates/user/*.toml`. Plugin-supplied templates (per ADR-020 signed-manifest discipline) merge via `extends`.

## Extending the library

- Add a preset → append a `_ct(...)` literal to `PRESETS` in `tools/generators/commit_templates.py`.
- Map a legacy v1 string to a preset → add it to that preset's `aliases` tuple.
- Explicitly filter a v1 string → add it to `FILTERED` with a one-line reason.
- Regenerate → `python tools/generators/all.py --only T-G-004 --write`.

## Architectural significance

Per §6.2 the Sange Domain layer is **VCS-agnostic** — a `Commit` doesn't know whether it came from Git or SVN. This table is the mapping the Adapter layer (`adapters/vcs/git.py`, `adapters/vcs/svn.py`, `adapters/vcs/hg.py`) uses to translate VCS-specific terminology into the abstract Domain. New VCS support = a new Adapter that fills out the rows in this table for that VCS; **zero changes** to Application or Domain layers.
